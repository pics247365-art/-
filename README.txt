שגאון — עמוד אתר עצמאי

מה יש כאן:
1. index.html — עמוד מלא מוכן להעלאה לאחסון.
2. wordpress-custom-html.txt — אותו קוד להדבקה בעמוד וורדפרס בתוך בלוק HTML מותאם אישית.

שימוש באחסון:
להעלות את index.html לתיקייה באתר, למשל:
public_html/shigaon/index.html

ואז הכתובת תהיה בערך:
https://yourdomain.co.il/shigaon/

שימוש בוורדפרס:
עמודים > הוסף חדש > בלוק HTML מותאם אישית > הדבק את התוכן של wordpress-custom-html.txt > פרסם.

הערה:
התמונות כרגע מגיעות מקישורים חיצוניים. אחרי שתבחר תמונות משלך, מחליפים את הקישורים בתמונות מהמדיה של וורדפרס.
