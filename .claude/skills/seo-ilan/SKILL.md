# סקיל — SEO לאילן לוי

## פרטי האתר
- **URL:** ilanlevi.com
- **פלטפורמה:** WordPress + Elementor + HostGator
- **שפה:** עברית ראשית, אנגלית משנית
- **קהל:** אנשים בודדים/קשישים ורמת השרון ואזורה

## מילות מפתח עיקריות
| מילת מפתח | כוונה |
|-----------|-------|
| ליווי אישי רמת השרון | מקומי, עיקרי |
| קשר אנושי | מותגי |
| מלווה אישי | שירות |
| הפחתת בדידות | כאב |
| חבר לקשישים | קהל |
| ליווי וקשר | כללי |

## מבנה דפים ו-SEO
| דף | Title Tag | Meta Description |
|----|-----------|-----------------|
| index.html | אילן לוי — ליווי וקשר אנושי ברמת השרון | ליווי אישי, שיחה וקפה, טיול ביחד. לא רופא. לא מטפל. פשוט אדם שנוכח. רמת השרון. |
| services | שירותי ליווי אישי — אילן לוי | ביקור בבית, שיחה, שחמט, טיול. ליווי ללא תלות. |
| projects | שגאון — פרויקט יצירתי | מסע בין דכאון שקט לשגעון רועש. צילום וכתיבה. |
| contact | צור קשר — אילן לוי | וואטסאפ, טלפון, רמת השרון. |

## כללי כתיבת תוכן SEO
- כותרת H1 אחת בלבד לכל דף
- מילת מפתח עיקרית ב-150 המילים הראשונות
- אורך מומלץ לדף: 300–500 מילים
- תמונות: alt text בעברית, שם קובץ עברי-אנגלי
- Internal links: קשר בין דפים קשורים

## מה לא לעשות
- אל תמלא מילות מפתח ("keyword stuffing")
- אל תשכפל תוכן בין דפים
- אל תשנה URL קיים ללא הפניה (301 redirect)

## כשמבקשים ניתוח SEO
1. בדוק title + meta description של הדף
2. בדוק H1 / H2 structure
3. בדוק אורך תוכן
4. בדוק internal links
5. בדוק alt text לתמונות
6. תן המלצות בסדר עדיפויות
